# حصن — Hisn Link Shield 🛡️
افحص أي رابط **قبل فتحه** واحمِ نفسك من الاحتيال المالي: كشف مواقع البنوك والجهات المقلدة، والروابط المختصرة، وصفحات رمز التحقق (OTP) الوهمية — مع حكم عربي واضح: 🟢 آمن / 🟡 مشبوه / 🔴 خطر، ومقارنة فورية بين الرابط المشبوه والموقع الرسمي.
**طبقات الاستخدام الأربع:**
1. 🧩 **إضافة المتصفح الصامتة** (Chrome/Firefox على الحاسوب، وFirefox/Kiwi/Edge على أندرويد، وSafari على آيفون عبر Safari Web Extension): فحص كل تنقل قبل تحميله، **نقطة ملونة بجانب كل رابط قبل لمسه**، جدار صلب على مستوى الشبكة، ووسم نتائج البحث.
2. 🛡️ **تطبيق أندرويد — معترض الروابط الذكي**: تعيين حصن «متصفحاً افتراضياً وسيطاً» — أي رابط من واتساب/SMS/الإيميل يفحص في أجزاء من الثانية: آمن؟ فتح فوري في كروم دون أن تشعر. خبيث؟ إيقاف + شاشة تحذير حمراء.
3. 🔔 **تطبيق أندرويد — مراقب الإشعارات**: `NotificationListenerService` الرسمية تفحص روابط الإشعارات فور وصولها وترسل تنبيهاً أحمر قبل فتح الرسالة.
4. 📩 **تطبيق iOS — فلتر الرسائل النصية الرسمي**: `ILMessageFilterExtension` تفحص كل رسالة SMS من مرسل غير معروف وتنقل الرسائل ذات الروابط الاحتيالية إلى «الرسائل غير المرغوب فيها» تلقائياً.
> بلا مكتبات خارجية، بلا build step، بلا قواعد بيانات — والتطبيقات المذكورة أعلاه صفر تبعيات أيضاً.
> ملاحظة: فكرة «اختصارات iOS» أُزيلت نهائياً من المستودع (واجهة، دالة `/api/shortcut`، إعادة توجيه، اختبارات، وثائق) — البدائل أعلاه بديلتها كاملة بآليات نظام رسمية موثقة.

## 1) النشر على Vercel (دقيقتان)
### الطريقة الأسهل — من الموقع
1. ارفع المستودع إلى GitHub (الأوامر أدناه).
2. افتح [vercel.com/new](https://vercel.com/new) واختر المستودع.
3. اضغط **Deploy** — لا إعدادات مطلوبة: Vercel يكتشف `public/` تلقائياً كواجهة و`api/` كدوال خادمية.
4. ستحصل على رابط مثل `https://hisn-xxx.vercel.app` — هذا هو موقعك، والخادم الموحد الذي يستخدمه كل شيء (الموقع، الإضافة، تطبيقا الهاتف، ملحق SMS).
### الطريقة البديلة — من الطرفية
```bash
npm i -g vercel
cd hisn
vercel --prod
```
### اختياري: طبقة التحليل الذكي (Gemini)
من إعدادات المشروع في Vercel ← Environment Variables:
- `GEMINI_API_KEY` = مفتاح Google AI Studio — يفعّل تحليل Gemini فوق المحرك المحلي (الأسوأ بين النتيجتين يحسم).
- `PCS_GEMINI_MODEL` = تجاوز اسم النموذج (اختياري — الافتراضي سلسلة نماذج تتبادل تلقائياً عند 404).
- `PCS_GEMINI_ENDPOINT` = نقطة نهاية مخصصة (اختياري — للاختبار أو وسيط خاص).
- `PCS_AI_ENDPOINT` / `PCS_AI_KEY` = طبقة AI عامة بديلة تُستخدم فقط إن لم يوجد مفتاح Gemini، تستقبل `{url, source, verdict}` وترد `{adjust: رقم, reason: نص}`.
بدون هذه المتغيرات يعمل الفحص القاعدي بالقواعد المحلية كاملاً.

## 3) البدائل الأربعة على الهاتف — الدليل السريع
الخريطة الكاملة والقيود النظامية الصادقة في **`mobile/README.md`**. باختصار:

### البديل 1 — الإضافة الصامتة (Android + iOS)
- **Android فوراً بلا حاسوب:** Firefox ← `about:addons` ← تثبيت من ملف (اضغط مجلد `extension/` في ZIP وغيّر الاسم إلى `extension.zip`) مع `manifest.v2.json`، أو استخدم Kiwi/Edge لتثبيت MV3 unpacked. بمجرد التثبيت تعمل: نقطة 🟢/🟡/🔴 بجانب كل رابط في كل صفحة — نتائج البحث والخرائط مشمولة.
- **iOS:** بناء Safari Web Extension بـ Mac — الدليل الكامل `safari-ios/README.md`. نفس النقاط الملونة + جدار الحجب يعملان داخل Safari.
- الإيقاف/التشغيل من نافذة الإضافة: خيار **«الوضع الصامت»**.

### البديلان 2 و3 — تطبيق أندرويد واحد (معترض + مراقب إشعارات)
1. افتح `mobile/android/` في Android Studio ← Build APK (دليل البناء داخل `mobile/android/README.md`).
2. ثبّت الـ APK ← افتح التطبيق ← **«تعيين حصن المتصفح الافتراضي»** (يفعّل معترض الروابط) ← **«منح وصول الإشعارات»** (يفعّل مراقب الإشعارات).
3. الصق رابط نشر Vercel في التطبيق ليقود الفحص السحابي (والقواعد المحلية تعمل دائماً كصمام).
4. جرّب: رابط في واتساب يُفحص قبل الفتح، وSMS برابط خبيث يرسل تنبيهاً قبل قراءة الرسالة.

### البديلان 2 و4 — تطبيق iOS (معترض + فلتر SMS)
1. Mac + Xcode: اتبع `mobile/ios/README.md` خطوة بخطوة (نسخ الملفات، إضافة الهدفين، التوقيع).
2. فلتر SMS يحتاج حساب Apple Developer مدفوع + موافقة Apple على صلاحية `message-filter` — طلب رسمي من Developer Portal.
3. بعد التثبيت: الإعدادات ← الرسائل ← تصفية الرسائل غير المعروفة ← اختر حصن. كل رسالة تحتوي رابطاً خبيثاً تذهب إلى «غير المرغوب فيها» تلقائياً.
## 4) تثبيت إضافة المتصفح على الحاسوب
1. نزّل المستودع (Code ← Download ZIP) وفك الضغط.
2. `chrome://extensions` ← **Developer mode** ← **Load unpacked** ← مجلد `extension`.
3. اختياري: من إعدادات الإضافة فعّل **الخادم السحابي** والصق رابط موقعك على Vercel — يدمج نتائج الخادم مع الفحص المحلي الفوري (الدرجة الأسوأ تحسم، وفشل الخادم لا يعطل الحماية).
> للنشر في متجر Chrome Web Store: اضغط مجلد `extension` في ZIP وارفعه في [لوحة المطورين](https://chrome.google.com/webstore/devconsole) (رسوم تسجيل لمرة واحدة). وللنشر على Firefox Add-ons استخدم `manifest.v2.json` في الحزمة.

## API
| Endpoint | الوظيفة |
|---|---|
| `GET /api/scan?url=...&source=search\|maps\|message\|sms\|interceptor\|notification&format=text` | فحص رابط → `{ok, verdict: {score, level, levelText, reasons[], comparison}, display}` — `display` نص عربي جاهز للعرض في التنبيهات، و`format=text` يرجع النص مباشرة بلا JSON |
| `POST /api/scan` | نفس الفحص عبر JSON `{url, source}` (يقبل JSON نصياً خاماً أيضاً) |
| `POST /api/report` | بلاغ `{url, note?, level?, source?}` |
| `GET /api/threats` | تجميع الحملات حسب النطاق والمصدر + السجل + البلاغات |
| `GET /api/health` | جاهزية + عدّادات + حالة طبقة AI + النموذج الفعّال |
- **CORS مفتوح** و`Access-Control-Allow-Origin: *` على كل الـ endpoints (تستخدمها الإضافة وتطبيقات الهاتف وملحق SMS).
- **حد معدل**: 120 طلب/دقيقة لكل IP لكل نسخة دالة.
- **ملاحظة صريحة**: سجل الفحوصات والبلاغات في ذاكرة كل نسخة دالة (ephemeral) — يُعاد بناؤه بعد إعادة النشر؛ للسجل الدائم اربط قاعدة بيانات لاحقاً.

## الخصوصية والحدود
- الإضافة افتراضياً: **صفر طلبات شبكة** — كل الفحص محلي في الجهاز؛ وضع السحابة اختياري بخدمتك.
- الخادم يفحص الرابط ويحفظ (النطاق + الدرجة + المصدر) في الذاكرة لدعم البلاغات — لا بيانات شخصية ولا محتوى صفحات.
- مراقب إشعارات أندرويد لا يخزن نص أي إشعار — يستخرج الرابط فقط، يفحصه، وينسى. ملحق iOS للرسائل يعمل بآلية Apple الرسمية ولا يرسل رسائل من الـ iOS إلى سوى خادمك.
- الفحص القاعدي قواعد محلية (لا WHOIS ولا قوائم حية إلا بربط طبقة AI) — والنتائج مؤشر لا حكم نهائي: لا تزال تعامل الروابط الحساسة بحذر.
- حدود النظامية الصادقة: iOS تمنع قراءة إشعارات التطبيقات (البديل 3 حصري لأندرويد)، وأندرويد ألغى فلاتر SMS (البديل 4 حصري لـ iPhone)، وفلتر iOS يعمل على مرسلي «غير معروف» فقط — كلها موثقة في `mobile/README.md`.
