# حصن على الهاتف — البدائل الأربعة الكاملة

> فكرة «اختصارات iOS» أُزيلت نهائياً من المستودع (الواجهة، الدالة `/api/shortcut`، إعادة التوجيه، الاختبارات، والوثائق). في مكانها هذه البدائل الأربعة التي لا تعتمد على ملفات `.shortcut` غير الموقعة إطلاقاً — بل على آليات نظام رسمية موثقة.

## خريطة البدائل

| # | البديل | المنصة | المجلد | آلية النظام المستخدمة |
|---|---|---|---|---|
| 1 | **الإضافة الصامتة** — نقطة 🟢/🟡/🔴 بجانب كل رابط قبل لمسه، تعمل فور تحميل الصفحة في الخلفية | متصفحات Android (Firefox/Kiwi/Edge/Samsung) + Safari على iOS | `extension/` + `safari-ios/` | WebExtension (content script) — يدعم MV3 وMV2 |
| 2 | **معترض الروابط الذكي** — المتصفح الوسيط: فحص في أجزاء من الثانية ثم فتح فوري أو شاشة حمراء | Android (تطبيق كامل) + iOS (تطبيق كامل) | `mobile/android/` + `mobile/ios/` | Android: intent-filter `VIEW http/https` (متصفح افتراضي) · iOS: تطبيق متصفح مع صلاحية `web-browser` + زر المشاركة |
| 3 | **مراقب الإشعارات** — فحص روابط الإشعارات فور وصولها وتنبيه أحمر قبل فتح الرسالة | Android فقط (iOS لا تسمح بقراءة إشعارات التطبيقات لنظاماً أمنياً مغلقاً) | `mobile/android/` | `NotificationListenerService` الرسمية |
| 4 | **فلتر الرسائل النصية المدمج** — نقل الرسائل ذات الروابط الاحتيالية إلى «غير المرغوب فيها» تلقائياً | iOS فقط (iPhone) | `mobile/ios/MessageFilterExtension/` | `ILMessageFilterExtension` الرسمية (IdentityLookup) |

## لماذا توزيع المنصات هكذا؟ (شفافية تقنية)

- **iOS تمنع** قراءة إشعارات التطبيقات الأخرى بأي طريقة — لهذا البديل 3 حصري لأندرويد عبر خدمته الرسمية.
- **أندرويد لا يملك** فلاتر SMS للتطبيقات منذ الإصدار 4.4 (الصلاحية حُصرت في التطبيق الافتراضي للرسائل) — لهذا البديل 4 حصري لـ iPhone عبر ملحق Apple الرسمي.
- البديل 1 يعمل على المنصتين لأن المتصفحين يتبعان معيار WebExtension المشترك.

## متطلبات التفعيل الفعلية (بلا مفاجآت)

| البديل | ما تحتاجه مرة واحدة |
|---|---|
| 1 — الإضافة الصامتة | Android: تثبيت الإضافة من Firefox/Kiwi · iOS: بناء Safari Web Extension بـ Mac (دليل `safari-ios/README.md`) |
| 2 — المعترض | Android: تثبيت التطبيق ثم «تعيين متصفحاً افتراضياً» · iOS: بناء التطبيق بـ Xcode + صلاحية `web-browser` |
| 3 — الإشعارات | Android: تثبيت التطبيق ثم «منح وصول الإشعارات» من الإعدادات |
| 4 — فلتر SMS | iOS: حساب Developer مدفوع + طلب صلاحية `message-filter` من Apple + بناء بـ Xcode + تفعيل الفلترة من إعدادات الرسائل |

## القواعد المحلية في كل مكان

كل بديل يعمل **حتى دون شبكة**:
- الإضافة: المحرك الكامل محلياً (`extension/rules/engine.js`).
- أندرويد: `ScanApi.scanLocal()` — قواعد خفيفة (IP، punycode، مختصرات، كلمات خطرة، انتحال بنوك).
- iOS: `SharedRules.swift` — نفس القواعد الخفيفة بمنفذ Swift.
- مع توفر الشبكة يعزز الجميع فحصه بالخادم السحابي الموحد `/api/scan` (الأسوأ بين النتيجتين يحسم).

## البدء السريع

```bash
# Android — بناء APK
cd mobile/android && gradle wrapper --gradle-version 8.7 && ./gradlew assembleDebug

# iOS — افتح Xcode واتبع mobile/ios/README.md

# الإضافة الصامتة على متصفح Android (Firefox مثلاً)
# chrome:// لا يعمل على الهواتف — على Firefox:
# about:config ← xpinstall.signatures.required = false (فقط للتجربة)
# ثم about:addons ← تثبيت من ملف ← اختر extension/manifest.v2.json بعد ضغطه zip
```

للنشر الرسمي: متجر Firefox Add-ons / Chrome Web Store للإضافة، Google Play للتطبيق، App Store لتطبيق iOS — الأدلة التفصيلية داخل كل مجلد.
