# حصن لأندرويد — معترض الروابط الذكي + مراقب الإشعارات

تطبيق أندرويد أصلي (Kotlin) ينفّذ البديلين 2 و3 من خطة الحماية، **صفر تبعيات خارجية** (لا AndroidX ولا أي مكتبة طرف ثالث) — كل الكود من `android.*` المدمج، وحجم الـ APK النهائي أقل من ميغابايت.

## ماذا يفعل التطبيق؟

### البديل 2 — معترض الروابط الذكي (Smart Link Interceptor)
- التطبيق يعلن نفسه **متصفحاً وسيطاً**: أي رابط تضغطه في واتساب أو SMS أو الإيميل يمر أولاً عبر حصن.
- الفحص يجري في خيط خلفي بمهلة **2.5 ثانية فقط** للسحابة، ومع سقوط محلي فوري عند غياب الشبكة — أجزاء من الثانية في المتوسط.
- **آمن؟** يُمرَّر الرابط فوراً إلى المتصفح الحقيقي (كروم) — المستخدم لا يرى سوى ومضة شفافة.
- **خبيث؟** يُوقف الفتح وتظهر **شاشة تحذير حمراء** كاملة: الدرجة، أسباب التصنيف بالعربية، النطاق المستهدف، زر «فتح الموقع الرسمي الصحيح» عند انتحال جهة معروفة، وتجاوز واعٍ بمسؤولية المستخدم يصمد 10 دقائق.
- **مشبوه؟** شاشة تنبيه كهرمانية بأزرار متابعة/رجوع.

### البديل 3 — مراقب الإشعارات (Notification Listener)
- خدمة `NotificationListenerService` الرسمية: تراقب إشعارات كل التطبيقات فور وصولها.
- تستخرج الروابط من نص الإشعار (العنوان + النص + النص الكبير)، تفحصها، وتتجاهل ما فُحص خلال 10 دقائق.
- عند كشف رابط خبيث/مشبوه تُرسل **إشعاراً عالي الأولوية** (🔔 + اهتزاز) بعنوان «🚨 حصن: رابط خبيث وصل في إشعار» مع اسم التطبيق المصدر والنطاق والحكم — **قبل أن يفتح المستخدم الرسالة**.
- الضغط على التنبيه يفتح شاشة التحذير الحمراء مباشرة.
- الخصوصية: لا يُخزَّن نص أي إشعار — يُستخرج الرابط فقط، يُفحص، ويُنسى.

## خطوات البناء (من Android Studio)

1. افتح Android Studio (Ladybug أو أحدث) ← **Open** ← اختر مجلد `mobile/android`.
2. انتظر مزامنة Gradle — ستُنزَّل أدوات البناء تلقائياً من مستودعات Google/Maven الرسمية فقط.
3. **Build ← Generate Signed App Bundle / APK** ← APK ← أنشئ keystore أو استخدم debug.
4. ثبّت الـ APK على الهاتف.

### من سطر الأوامر
```bash
cd mobile/android
gradle wrapper --gradle-version 8.7    # مرة واحدة — ينشئ ./gradlew
./gradlew assembleDebug                # الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## خطوات التفعيل على الهاتف (دقيقتان)

### تفعيل معترض الروابط (البديل 2)
1. افتح التطبيق ← اضغط **«تعيين حصن المتصفح الافتراضي»**.
2. في شاشة النظام: **التطبيقات الافتراضية ← تطبيق المتصفح ← اختر حصن**.
3. انتهى — جرّب: أرسل لنفسك رابطاً في واتساب واضغطه؛ سترى ومضة فحص ثم الفتح أو التحذير.

### تفعيل مراقب الإشعارات (البديل 3)
1. في التطبيق اضغط **«منح وصول الإشعارات»**.
2. في شاشة النظام: فعّل **السماح لوصول الإشعارات** لحصن.
3. انتهى — جرّب: أرسل لنفسك رسالة SMS تحتوي رابطاً خبيثاً؛ سيرد تنبيه حصن خلال ثوانٍ.

### ربط الخادم السحابي
- في التطبيق الصق رابط نشر Vercel الخاص بك (مثل `https://hisn-xxx.vercel.app`) واحفظ.
- بدونه يعمل التطبيق بالقواعد المحلية المدمجة فقط (كشف IP، النطاقات المقلدة الشائعة، المختصرات، الكلمات الخطرة، Punycode) — أضعف من المحرك الكامل لكنها كافية كصمام أمان عند انقطاع الشبكة.

## ملاحظات تقنية

| النقطة | التفصيل |
|---|---|
| الحد الأدنى | Android 7.0 (minSdk 24) |
| الهدف | Android 14 (targetSdk 34) |
| التبعيات | صفر — `HttpURLConnection` + `org.json` المدمجة |
| الصلاحيات | `INTERNET` + `BIND_NOTIFICATION_LISTENER_SERVICE` (يمنحها النظام بعد موافقتك) |
| معرف الحزمة | `com.hisn.shield` — غيّره في `app/build.gradle` قبل النشر على Google Play |
| النشر | لا حاجة لحساب مطور للتجربة الشخصية؛ للنشر رسمياً حساب Google Play (25$ مرة واحدة) |
| بطارية | الفحص لنقرة واحدة يعمل على خيط واحد وينتهي بأجزاء من الثانية — أثر البطارية مهمل |
