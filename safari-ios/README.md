# الإضافة الصامتة على Safari للآيفون (البديل 1) — دليل البناء

هذا المجلد يحتوي الدليل لتحويل إضافة حصن الموجودة (`extension/`) إلى **Safari Web Extension** تعمل على آيفون/آيباد، لتصبح **الإضافة الصامتة الكاملة**: بمجرد تحميل أي صفحة تقرأ كل الروابط الظاهرة (نتائج البحث والخرائط) وتضع بجانب كل رابط نقطة ملونة (🟢 آمن / 🟡 مشبوه / 🔴 خطر) **قبل أن يلمسه المستخدم** — بالتوازي مع جدار الفحص قبل فتح أي صفحة، والاعتراض عند الروابط الخبيثة.

## لماذا هذا الملف؟

Apple توزّع إضافات Safari على iOS داخل **تطبيق iOS** (لا يمكن تثبيت مجلد إضافة مباشرة كما في Chrome). الطريقة الرسمية هي أداة Apple المدمجة `safari-web-extension-converter` في Xcode، وهي تحوّل إضافتنا تلقائياً إلى مشروع تطبيق جاهز. لا يمكن تنفيذ هذه الخطوة من داخل آيفون وحده — تحتاج حاسوب Mac مرة واحدة للبناء.

## المتطلبات

- حاسوب Mac مع **Xcode 15** أو أحدث (مجاني من App Store).
- آيفون/آيباد بنظام **iOS 16.4+** (يفضل iOS 17+).
- حساب Apple ID عادي: يكفي للتثبيت على جهازك (التوقيع المجاني يُجدد كل 7 أيام)، أو حساب Apple Developer (99$/سنة) للتثبيت الدائم والنشر في App Store.

## خطوات البناء (10 دقائق تقريباً)

### 1) انقل مجلد الإضافة إلى الـ Mac
نزّل المستودع من GitHub وفك الضغط، ثم في الطرفية:

```bash
xcrun safari-web-extension-converter /path/to/hisn/extension \
  --project-location ~/Hisn \
  --app-name "حصن" \
  --bundle-identifier com.yourname.hisn \
  --ios-only
```

> الأداة تولّد مشروع Xcode كاملاً (التطبيق الحاوي + الإضافة + الصلاحيات). لو سألتك عن «background mode» اختر non-persistent.

### 2) افتح المشروع وفعّل التوقيع
- افتح `~/Hisn` في Xcode.
- اختر الهدف (Target) الرئيسي ← Signing & Capabilities ← فعّل **Automatically manage signing** واختر حسابك (Team: Personal Team).
- كرر نفس التوقيع لهدف الإضافة `حصن Extension` (Target الثاني).

### 3) شغّله على الآيفون
- وصّل الآيفون بالـ Mac ← اختره من قائمة الأجهزة في Xcode ← Run (▶).
- في الآيفون: الإعدادات ← عام ← إدارة VPN والأجهزة ← وثّق المطور (حسابك) — هذا هو «طلب الإذن» النظامي الأول.

### 4) فعّل الإضافة في Safari
- الإعدادات ← Safari ← الامتدادات ← **حصن** ← شغّلها.
- اختر **All Websites** ← Allow ← «السماح» — هذا إذن الوصول التلقائي للصفحات (يمكن تقييده لاحقاً).
- اختياري: اسمح بالإشعارات لتظهر تنبيهات الحجب.

### 5) ماذا ستحصل؟
- **الوضع الصامت (البديل 1):** أي صفحة تفتحها تُمسح فوراً — كل رابط يظهر بجانبه نقطة ملونة قبل لمسها، بلا أي عنصر آخر يزاحم الصفحة.
- **جدار الفحص:** الروابط الخبيثة تُحجب قبل تحميلها بشاشة اعتراض فيها المقارنة مع الموقع الرسمي وزر تجاوز واعٍ.
- نتائج البحث موسومة بشارات تفصيلية، وأيقونة الإضافة تعرض فحصاً يدوياً للصفحة الحالية.
- الإعدادات تعمل كما هي من نافذة الإضافة: إيقاف/تشغيل الوضع الصامت، الحجب، الجدار الصلب، وضع السحابة.

## ملاحظات توافق معروفة

- الإضافة تستخدم `webNavigation` و`storage` و`tabs` و`declarativeNetRequest` وحقن محتوى — كلها مدعومة في Safari 16.4+.
- **إذا كان Safari قديماً (أقل من 16.4):** استخدم متغاير MV2 — انسخ `extension/manifest.v2.json` فوق `extension/manifest.json` قبل تشغيل المحوِّل؛ نفس الكود يعمل (الخلفية عبر background.html).
- الوضع الصامت يعمل بالمحرك المحلي بالكامل — **صفر طلبات شبكة** من نقاط الفحص.
- الخطوط والواجهة عربية RTL وتعمل كما هي.

## بدون Mac؟

حينها استخدم البدائل الأخرى المخططة حسب المنصة:
- **Android:** الإضافة الصامتة تثبَّت مباشرة في Firefox/Kiwi/Edge (بلا حاسوب) — انظر `mobile/README.md`.
- **iOS بلا Mac:** البديل 2 (معترض الروابط) والبديل 4 (فلتر SMS) يحتاجان Mac أيضاً حتماً — بناء أي تطبيق iOS يمر عبر Xcode. للاستخدام الفوري الوحيد المتبقي هو موقع حصن نفسه: الصق الرابط وافحصه بنقرة.
